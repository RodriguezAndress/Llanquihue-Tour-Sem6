Llanquihue Tour es un sistema automatizado de una agencia de turismo que busca facilitar el trabajo y evitar errores que puedan ocurrir con el registro manual.
En este caso se aplica el uso de Override para la sobreescritura en herencia y el uso de polimorfismo.
En este caso no se uso el registro y lectura de archivo txt como en los jerecicios pasados sino que se pasa la informacion directamente sin lectura del archivo aunque sigan existiendo sus carpetas; Aun asi sigue funcionando con un ArrayList que captura distintos tours con 
parametros como nombre, tipo de tour y duración.

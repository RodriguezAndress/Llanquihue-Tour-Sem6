Llanquihue Tour es un sistema automatizado de una agencia de turismo que busca facilitar el trabajo y evitar errores que puedan ocurrir con el registro manual.
En este caso se aplica el uso de interfaz, herencia y poliformismo, además del registro y lectura de archivo txt, un ArrayList que captura distintos datos  
de quienes supondria serian los trabajadores de la empresa.
